# Implementation Plan: Doctor CMS — Content Management for Single-Site

**Branch**: `V3` | **Date**: 2026-07-03 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `specs/003-doctor-cms/spec.md`

## Summary

A lightweight Node.js Express CMS backend (`cms/`) running on port 5050 that lets the doctor edit `config/doctor-profile.json` through an authenticated admin panel. The public static website is unchanged — it continues to read from `config/doctor-profile.json` via Nginx. The CMS adds auth-protected editing, a draft-preview-publish workflow, photo uploads, testimonial CRUD, and expertise CRUD. The admin panel frontend is pure HTML/CSS/Vanilla JS (no frameworks).

## Technical Context

**Language/Version**: Node.js 18 LTS (backend) + HTML5/CSS3/Vanilla JS ES2020+ (admin frontend)

**Primary Dependencies**: `express@^4`, `express-session`, `session-file-store`, `multer`, `bcryptjs`, `uuid`, `express-rate-limit`, `dotenv`

**Storage**: File system — `config/doctor-profile.json` (live), `backups/content.draft.json` (draft), `backups/config.{ts}.json` (versioned backups), `uploads/` (images), `cms/sessions/` (session files)

**Testing**: Node.js built-in `node:test` + manual scenario validation from quickstart.md

**Target Platform**: Linux VPS (Ubuntu + Nginx), developer machine (Windows/macOS for local dev)

**Project Type**: Web application (admin CMS — local backend + SPA admin panel)

**Performance Goals**: Admin panel load < 2s; publish operation < 500ms; public site LCP unchanged (< 1.5s)

**Constraints**: Port 5050; no React/Vue; no WYSIWYG editor; plain text fields; separate from existing `admin/` (port 3500); expertise detail content in `scripts/expertise-details.js` is out of scope v1

**Scale/Scope**: 1 doctor user, ~20 config sections, 17 expertise items, ~20 testimonials, 50+ gallery images max

## Phase 0: Research Output

All key technical decisions resolved. See [research.md](research.md) for full rationale.

| Decision | Chosen Approach |
|----------|----------------|
| Session management | `express-session` + `session-file-store` |
| Password storage | bcryptjs hash stored in `.env` |
| Atomic publish write | `writeFileSync(tmp)` → `renameSync()` → config path |
| Preview interception | `URLSearchParams` check in `app.js`; fetch `/api/preview/config` with `credentials: 'include'` |
| CMS directory | New `cms/` at port 5050; existing `admin/` at port 3500 unchanged |
| Uploads serving | `express.static('uploads/')` proxied by Nginx at `/uploads/` |

            ├── GET  /api/content          → read live config
            ├── PUT  /api/content          → save draft

            ├── POST /api/publish          → atomic publish draft → live
            ├── GET  /api/backups          → list last 5 backups
            ├── POST /api/rollback         → restore a backup
            └── POST /api/upload           → upload image
```
